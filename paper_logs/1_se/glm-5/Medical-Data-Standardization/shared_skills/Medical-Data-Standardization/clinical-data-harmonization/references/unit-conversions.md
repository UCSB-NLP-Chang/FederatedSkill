# Unit Conversion Reference

## SI to US Conventional Unit Conversions

### Electrolytes

| Analyte | SI Unit | US Unit | Conversion Factor | Threshold to Detect SI |
|---------|---------|---------|-------------------|------------------------|
| Sodium | mmol/L | mEq/L | 1:1 | N/A (same) |
| Potassium | mmol/L | mEq/L | 1:1 | N/A (same) |
| Chloride | mmol/L | mEq/L | 1:1 | N/A (same) |
| Bicarbonate | mmol/L | mEq/L | 1:1 | N/A (same) |
| Magnesium | mmol/L | mg/dL | ×0.411 | > 2.5 suggests mmol/L |
| Calcium | mmol/L | mg/dL | ×4.0 | > 15.0 suggests mmol/L |

**Note on Magnesium threshold**: Normal US range is 1.5-2.5 mg/dL. Normal SI range is 0.6-1.0 mmol/L (which converts to 1.5-2.4 mg/dL). Therefore, values >2.5 are likely already in mg/dL, and values 0.6-2.5 could be either. Use clinical context or other SI markers in the same row to decide. When in doubt, check if the value makes clinical sense after conversion.

## Threshold Logic

Values outside normal US conventional ranges may indicate SI units:
- **Magnesium**: Normal US range 1.5-2.5 mg/dL; values >2.5 likely already in mg/dL; SI values (0.6-1.0 mmol/L) convert to 1.5-2.4 mg/dL
- **Calcium**: Normal US range 8.5-10.5 mg/dL; values >15.0 likely mmol/L
- **Glucose**: Normal US range 70-140 mg/dL; values <30.0 likely mmol/L
- **Creatinine**: Normal US range 0.7-1.3 mg/dL; values >20.0 likely μmol/L
- **Bilirubin**: Normal US range 0.1-1.2 mg/dL; values >20.0 likely μmol/L
- **Albumin**: Normal US range 3.5-5.0 g/dL; values >20.0 likely g/L
- **Hemoglobin**: Normal US range 12-17 g/dL; values >20.0 likely g/L
- **Free T4**: Normal US range 0.8-1.8 ng/dL; values >5.0 likely pmol/L
- **Total T4**: Normal US range 4.5-12.5 μg/dL; values >25.0 likely nmol/L
- **Total T3**: Normal US range 80-200 ng/dL; values <50.0 likely nmol/L
- **PTH**: Normal US range 10-65 pg/mL; values >500 likely pmol/L
- **Vitamin D**: Normal US range 30-100 ng/mL; values >150 likely nmol/L
- **WBC Count**: Normal US range 4500-11000 cells/µL; values <100 likely ×10^9/L
- **Uric Acid**: Normal US range 3-7 mg/dL; values >20 likely μmol/L
- **pO2**: Normal US range 75-100 mmHg; values <20 likely kPa
- **pCO2**: Normal US range 35-45 mmHg; values <20 likely kPa
- **Lactate**: Normal US range 4.5-20 mg/dL; values <5 likely mmol/L

## Conversion Direction Guide

When SI value exceeds threshold:
- **Divide by factor**: Free T4, Total T4, Creatinine, Bilirubin, Albumin, Total Protein, Hemoglobin, Vitamin D, Uric Acid
- **Multiply by factor**: PTH, Calcium, Magnesium, Phosphorus, Glucose, Free T3, Total T3, WBC Count, pO2, pCO2, Lactate

Rule of thumb: If SI unit is "smaller" (pmol, nmol, μmol), the SI numeric value is typically larger than the US value → divide. If SI unit is "larger" (mmol), the SI numeric value is typically smaller → multiply.

## Number Format Patterns

| Format | Example | Parsing Approach |
|--------|---------|------------------|
| Scientific notation | `5.6949e+00` | `float(value)` |
| Comma decimal | `"142,0205"` | `float(value.replace(',', '.'))` |
| Quoted numeric | `"12,4787"` | Strip quotes, then parse |
| Missing/empty | ``, `nan` | Check before parsing; decide handling |

## Output Formatting

- Round to 2 decimal places: use `f"{value:.2f}"` to ensure exactly 2 decimals
- Avoid scientific notation in output: use `:.2f` format specifier
- No commas in decimals: use `.` as decimal separator
- Note: `round(value, 2)` produces `5.6` but `f"{value:.2f}"` produces `5.60`
